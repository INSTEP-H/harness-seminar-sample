# 해석 톤 · 구조 가이드

draft 단계의 sub-agent가 reveal 프레임 본문을 쓸 때 참조한다.

## 1. 톤

- **2인칭 화법**: "당신", "그 사람" 으로 청자를 직접 호명한다. "이 카드를 뽑은 분은…" 같은 3인칭 화법 회피.
- **부드러운 어미**: "~네요", "~ 같아요", "~ 거예요" 우선. 단정 어미("~한다", "~다") 빈도 낮게.
- **단정 대신 가능성**: "~할 것이다" 보다 "~하고 있는 것 같아요" / "~할 수 있어요".
- **한 호흡**: 긴 만연체는 피하되, 한 문장이 너무 짧으면 단호해 보인다. 짧은 문장 + 호흡 긴 문장 1~2개를 섞는다.

## 2. 본문 구조 (reveal 프레임 기준)

다음 4단 구조를 권장한다. 매번 모두 채울 필요는 없지만 1·4번은 항상 있어야 한다.

1. **상태 호명** (1-2 문장) — "이 카드를 고른 당신, 요즘 ~한 시기를 지나고 있는 것 같아요." 청자의 현재를 짚어주며 시작.
2. **카드의 의미 풀이** (1-2 문장) — 카드 키워드를 직설하지 않고 청자의 상황에 녹여 풀어 쓴다.
3. **변화·조언** (선택, 1-2 문장) — 가까운 시일 내 일어날 일 또는 시청자가 가져갈 작은 행동 한 가지.
4. **닫는 문장** (1 문장) — 따뜻한 위로 또는 가능성의 여지. 강한 단정으로 끝맺지 않는다.

## 3. 길이

- 본문 총 길이: 250~320자 (reels 프레임 3 본문 슬롯 기준).
- 문단 분리: 1-2 문장 단위로 줄바꿈. safe_zone 안에 본문이 들어가도록 frame-composer가 자동 폰트 크기 조정.

## 4. 자제할 표현

- 점쟁이 클리셰: "운명입니다", "필연입니다", "절대 ~합니다".
- 광고 직설: "지금 가입", "100% 적중", "데일리타로의 전문가가" 등.
- 부정의 강조: "절대 안 됩니다", "조심하세요" 같은 단정 경고. (대신 "조금 더 살펴보면 좋을 시기예요" 식으로 부드럽게.)
- 종교적 단언: 특정 종교/신앙 단어 사용 금지.

## 5. 작성 체크 (self-check)

작성 후 sub-agent가 스스로 점검한다:

- [ ] 2인칭 화법으로 시작했는가
- [ ] 단정 어미가 3개 이상 연속되지 않는가
- [ ] 본문 길이가 250~320자 범위인가
- [ ] 카드 의미를 직설하지 않고 상황으로 풀어 썼는가
- [ ] 닫는 문장이 가능성의 여지를 남기는가
- [ ] forbidden 표현(brand-voice.yaml)을 사용하지 않았는가

## 6. 예시 (good vs bad)

| 좋음 | 나쁨 |
|---|---|
| "이 카드를 고른 당신, 요즘 한 사람의 시선이 묘하게 신경 쓰이지 않나요." | "당신은 무조건 누군가에게 사랑받고 있습니다." |
| "그 사람의 마음 안쪽에는 아직 꺼내지 못한 한 줄이 남아 있어요." | "그 사람의 마음은 100% 당신에게 향해 있습니다." |
| "조금만 기다려보세요. 답은 의외로 가까이에 있어요." | "지금 바로 그 사람에게 연락하세요!" |
